# המשימות שלי

מערכת אישית חכמה לניהול משימות, בעברית מימין לשמאל, עם סוכן AI (GPT-6 Luna).

- מרחבים עם צבע ותצוגה לבחירה: קנבן, רשימת TODO, לוח שנה
- דשבורד: דחוף, להיום, באיחור וכרטיס לכל מרחב
- סוכן בצ'אט עם 5 כלים (קריאה, הוספה, עדכון, מחיקה, סיכום), פועל רק על ההקשר שנבחר, ומבקש אישור לפני פעולה על יותר מ-3 משימות או מחיקה
- כניסה בסיסמה אחת (`APP_PASSWORD`). כל דף ו-API חסומים בלי התחברות (`proxy.ts`)
- חגי ישראל בלוח השנה: חגים, ערבי חג, חול המועד, צומות, חנוכה, ראש חודש וימי מדינה. שישי ושבת מסומנים בצבע רקע פסטלי אחד. ימי חג, ערבי חג, חול המועד וחנוכה מסומנים בצבע פסטלי אחר

## הרצה

```bash
npm install
npx vercel env pull env/.env   # או: cp .env.example env/.env וממלאים
npm run db:setup               # יוצר טבלאות
npm run db:seed                # נתוני דוגמה (רק אם אין נתונים)
npm run db:holidays            # חגים מתחילת החודש ועד 3 שנים קדימה
npm run dev
```

## חגים

הנתונים מגיעים מ-[Hebcal](https://www.hebcal.com) (רישיון CC BY 4.0), בלוח של ישראל. נשמרים רק המועדים ש-calendar.2net.co.il מציג, והרשימה נמצאת ב-`RULES` בקובץ `scripts/import-holidays.ts`. הנתונים נשמרים בטבלה `ms_holidays` ולא כמשימות, ולכן לא מופיעים ברשימות, בקנבן ובסוכן.

- `npm run db:holidays` מחליף את כל מה שנמצא בטווח, וכך אפשר להריץ אותו שוב בבטחה. אפשר להוסיף `--years 5` או `--dry-run` (הדפסה בלי כתיבה).
- הנתונים מכסים 3 שנים, ונגמרים בסוף נובמבר 2029. לפני כן צריך להריץ את הייבוא שוב.

הסקריפטים קוראים את `env/.env`, ואז `.env.local` ו-`.env`. כל קבצי ה-env מוחרגים מ-git.

## סנכרון Google Calendar

הסנכרון הוא חד-כיווני, מ-Google לאפליקציה, דרך הכתובת הסודית של כל יומן. לא צריך OAuth.

1. ב-Google Calendar פותחים הגדרות, בוחרים יומן, ובקטע "שילוב היומן" מעתיקים את "כתובת סודית בפורמט iCal".
2. ב-Vercel מוסיפים משתנה `GCAL_ICS_<spaceId>` עם הכתובת, ומסמנים אותו כ-Sensitive. `<spaceId>` הוא המספר שבכתובת המרחב, `/space/<id>`. אחרי זה פורסים מחדש.

- **מתי רץ:** כשהאפליקציה נפתחת או חוזרת לחזית, לכל היותר פעם ב-5 דקות. אפשר גם ידנית: `npm run gcal:sync`, ועם `--dry-run` רק מציג מה ישתנה.
- **מה Google קובע:** שם, תאריך ושעה. השעה נכתבת בתיאור המשימה. סטטוס, עדיפות ומרחב נשארים בשליטת האפליקציה.
- **אירוע שנמחק ב-Google** נמחק גם כאן. משימה מסונכרנת שנמחקה באפליקציה תחזור בסנכרון הבא.
- **טווח:** מתחילת החודש הקודם ועד 3 שנים קדימה. אירועים חוזרים נפרשים רק ל-90 הימים הקרובים.
- **משימות ישנות:** משימה קיימת במרחב עם אותו שם ותאריך מקושרת לאירוע ולא משוכפלת.
- הקוד ב-`lib/gcal.ts`, והטסט ב-`npm run test:gcal`.

## משתני סביבה

| משתנה | תיאור |
|---|---|
| `DATABASE_URL` | חיבור ל-Postgres |
| `OPENAI_API_KEY` | מפתח OpenAI לסוכן |
| `APP_PASSWORD` | הסיסמה לכניסה למערכת. בלעדיה אי אפשר להיכנס |
| `SESSION_SECRET` | מומלץ. סוד לחתימת ה-session ואישורי הסוכן (ברירת מחדל: נגזר מ-`DATABASE_URL`) |
| `OPENAI_MODEL` | אופציונלי, ברירת מחדל `gpt-6-luna` |
| `GCAL_ICS_<spaceId>` | אופציונלי, סוד. הכתובת הסודית בפורמט iCal של יומן Google. האירועים שלו נכנסים כמשימות למרחב `<spaceId>`. אפשר להגדיר כמה כאלה |

שינוי `APP_PASSWORD` מנתק את כל ה-sessions הקיימים.

הטבלאות נושאות קידומת `ms_` כדי לא להתנגש בטבלאות אחרות באותו מסד.
